01 · Runtime

当前运行时架构

浏览器只接入 Go API；Go 是唯一的业务编排与写库入口；Agent 不连接 PostgreSQL，只负责 AI 生成与质量审校。

02 · Player Flow

一次选择如何流式续写

正文可以先抵达玩家；结构化元数据、去重和事务持久化在流结束后完成。审校要求重写时，前端收到 revise 后清空当前草稿再接收新正文。

03 · Agent Quality

Agent 质量闭环：当前单流水线

当前实现是单条 _stream_pipeline，不是多 Agent 编排。审校只拦截硬伤：无法通过时降级交付最后一稿，保证玩家操作不会因为质量审校失败而中断。
