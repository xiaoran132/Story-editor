段 3 · 属性

玩家状态由你定义

属性是玩家做选择的依据。每定义一个可见属性,左边的天空就多一颗星。

数值 累加:每次变化加减,如体力 +1 / −2。
标量 覆盖:后一次直接盖掉前一次,如所在位置。
集合 增删:按元素增删,如背包、已知线索。
隐藏:玩家永远看不到它,只有 AI 读它——它不会出现在天空里。
渐显:剧情揭示后才出现在玩家面板里——天空里先画成一圈待亮的虚线。
