## 1. 文档维护与交付原则

**页面有变动时，只更新当前态，不追加历史日志。**

1. 改对应的逐页章节（§7）：写清页面目的、主要区域、交互结果、路由与响应式边界。
2. 若动了 token、hue 规则、动效参数或数据契约，更新 §2–§6 与 §8 的对应表。
3. 已废弃的入口、参数或页面说明直接删除或改写为当前状态；不要在本文件保留“曾经如何修改”的过程。

同步的判断标准：**前端只读本文件，能否实现当前页面且不会做出假入口、错误路由或不一致的视觉。**

### 文档校验

- `DESIGN.md` 的修改时间不得早于本轮改动的页面文件；
- 每个实际 HTML 页面都必须在 §7 的页面总览和逐页章节中出现；
- 文档中的页面入口必须指向当前存在的文件，未实现能力须明确标成边界，而不是写成链接。

### 写文件的硬要求

所有含中文的项目文件**必须显式以 UTF-8 写入**。禁止使用不带编码参数的 `Set-Content` / `Add-Content`，禁止存成 UTF-16。写完后确认没有 BOM、NUL、替换字符或连续的字面 `?`。

## 2. 一句话主张

**产品不是装作品的白盒子,产品就是那片由想象力构成的星空本身。**

视觉语言 = **剪影 × 天空**。角色是零细节的纯黑 SVG 剪影(姿态即性格),世界是 CSS/SVG 生成的渐变天空 + 云 + 星 + 流星,构图**人小天大**(人物占比 <15%)。

**白底已被明确否决。** 深空墨底是让作品缤纷色发光的物理前提。

## 3. 全局 token

每个页面在 `:root` 声明同一套基底。**不新造 hex,派生色一律 `oklch()`。**

```css
:root{
  --bg:        oklch(0.13 0.022 265);   /* 深空墨底,近黑不纯黑 */
  --bg-deep:   oklch(0.09 0.018 265);   /* 页面底,比 --bg 更深 */
  --surface:   oklch(0.19 0.030 265);
  --fg:        oklch(0.96 0.010 90);
  --muted:     oklch(0.72 0.020 265);
  --border:    oklch(1 0 0 / 0.11);
  --border-2:  oklch(1 0 0 / 0.20);
  --accent:    oklch(0.82 0.125 85);    /* 暖金 · 全站唯一强调 */
  --accent-dim:oklch(0.66 0.100 85);

  --font-display:"Noto Serif SC", Georgia, "Songti SC", serif;
  --font-ui:"Inter", system-ui, -apple-system, "Segoe UI", sans-serif;

  --r-sm:8px; --r-md:12px; --r-lg:18px; --r-pill:999px;
  --ease:cubic-bezier(.2,0,0,1);        /* M3 standard */

  /* 双层焦点环:内圈压深底,外圈暖金。单层暖金落在亮态按钮上会消失。 */
  --ring:0 0 0 2px oklch(0.09 0.018 265), 0 0 0 4px oklch(0.82 0.125 85);

  --ambient-hue:252;                    /* 当前所在世界的色相 */
}
```

**每屏稳定态最多 2 处,且不参与 hue 染色。** 焦点环(`--ring`)与表单聚焦边框用暖金,但那是瞬时态,不计入配额。

各页的 2 处分别是:

| 页面 | 第 1 处 | 第 2 处 |
|---|---|---|
| `home-galaxy.html` | 品牌标记里的圆点 | 聚焦面板的「走进这个世界」 |
| `works-library.html` | 品牌标记里的圆点 | 卡片主动作 |
| `play-story.html` | 品牌标记里的圆点 | 当前可选的主选项 |
| `reading-history.html` | 品牌标记里的圆点 | 「接着读」条的主动作(无在读记录时该条整块隐藏,配额降为 1 处) |
| `community.html` | 品牌标记里的圆点 | 分叉弹层的「建立分支」 |
| `derivation-graph.html` | 品牌标记里的圆点 | 节点面板的「从这个节点分叉」 |
| `create-editor.html` | 品牌标记里的圆点 | 段 6 的「发布这个世界」 |
| `profile-space.html` | 品牌标记里的圆点 | 主动作槽(本人 =「继续那 N 片没写完的天空」/ 访客 =「关注」) |
| `profile-drafts.html` | 品牌标记里的圆点 | 「接着写」条的主动作 |
| `profile-inbox.html` | 品牌标记里的圆点 | **不用满配额**(未读点与筛选选中态一律中性亮态) |
| `profile-settings.html` | 品牌标记里的圆点 | 保存条的「保存修改」 |
| `login.html` | 品牌标记里的圆点 | **两态互斥**:表单态 = 主 CTA「让它开始」/ 确认态 = L5 的暖金地平线 |
| `404.html` | 品牌标记里的圆点 | 唯一实心出口「回到星海」 |

> `profile-space.html` 的主动作槽**两态互斥**:本人视角与访客视角永远只渲染其中一个,不会同屏出现两个实心按钮。访客点「关注」后按钮退成描边中性态,配额随之释放为 1 处。
> `reading-history.html` 的列表行动作「继续 / 重读」一律描边中性态,筛选选中态与「本机存档」标记用中性亮态 `oklch(0.88 0.008 265)`,删除确认的破坏性按钮同样用中性亮态,均不占暖金。
> `profile-drafts.html` 的列表行动作「继续」一律描边中性态;实心暖金只在顶部「接着写」条上出现一次,指向最近改过的那一份。删除确认的破坏性按钮用中性亮态 `oklch(0.88 0.008 265)`,不占暖金。
> `profile-settings.html` 的主题色块选中态、姿态选中态、单选与勾选标记一律中性亮态,不占暖金。

> `community.html` 的卡片主动作「从这里分叉」**默认是描边按钮,仅在该卡 hover/聚焦时变实心中性亮态**。因此同屏永远只有一个实心主按钮,不与行动经济冲突,也不占暖金。
> `derivation-graph.html` 的分叉弹层提交键同理用中性亮态 `oklch(0.88 0.008 265)`,配额已给面板。
> `create-editor.html` 的段 1–5 主动作是「保存草稿」,一律描边中性态;实心暖金主 CTA **只在段 6 出现一次**,且体检未过时 `disabled`。段落轨的「已就绪」勾、题材/主题的选中态一律用中性亮态 `oklch(0.88 0.008 265)`,不占暖金。

## 4. hue 系统(技术核心)

**每部作品一个 `--hue`(0–360),驱动整套配色。规则:每个角色 token 的 L 和 C 写死,只有 H 用 `var(--hue)`。** 这样换色相时明度/饱和层级不会崩。

```css
.world-scope{
  --w-line:   oklch(0.72 0.140 var(--hue) / .85);
  --w-glow:   oklch(0.72 0.140 var(--hue) / .50);
  --w-glow-lg:oklch(0.72 0.140 var(--hue) / .55);
  --w-sky-hi: oklch(0.34 0.115 var(--hue));
  --w-sky-md: oklch(0.22 0.085 var(--hue));
  --w-sky-lo: oklch(0.11 0.040 var(--hue));
  --w-halo:   oklch(0.48 0.130 var(--hue) / .75);
  --w-cloud:  oklch(0.20 0.050 var(--hue) / .85);
  --w-cloud2: oklch(0.44 0.090 var(--hue) / .50);
  --w-star:   oklch(0.98 0.020 var(--hue) / .90);
  --w-ink:    oklch(0.055 0.015 var(--hue));   /* 剪影色 */
  --w-plate:  oklch(0.050 0.015 var(--hue) / .92);
  --w-text:   oklch(0.97 0.010 var(--hue));
  --w-kick:   oklch(0.86 0.090 var(--hue));
}
```

### ⚠️ `--w-cloud` 只能压在比它更暗的天空上

`--w-cloud` 的 L 是 **0.20**,而 `--w-sky-md` 是 **0.22**、`--w-sky-hi` 是 **0.34**。把它画在中高段天空上是**负对比**——云层点亮了也看不见。这个坑 `login.html` 与 `create-editor.html` 各踩过一次(见 §7.6、§7.7)。

规则:云要盖在天空的中高段,就别用 `--w-cloud`,改用 `--w-cloud2`(0.44)或页面内自取一档 `oklch(0.40–0.52 …)`;`--w-cloud` 只适合压在 `--w-sky-lo`(0.11)那一档的低空。**任何按层显现的画面,每一层相对它盖住的底层至少要有 0.10 的 L 差**,否则那一层等于没做。

### ⚠️ 这组 token 必须声明在使用它的元素上,不能放 `:root`

CSS 自定义属性在**声明处**就完成 `var()` 替换。放 `:root` 会被永久锁死成根 hue,每张卡就都同一个色了。

实际挂载点:`.work`(星系卡)· `.pane` / `.avatar` / `.creator`(社区)· `.starmap` / `.listview` / `.legend` / `.wchip` / `.panel` / `.modal-panel`(星图)· `.scene` / `.stagefig`(游玩页)· `.authorsky` / `.sky-layer` / `.work` / `.row` / `.readout` / SVG 里的每个 `<g class="world-scope">`(个人空间)· `.draft` / `.resume`(草稿箱)· `.msg`(消息)· `.pv` / `.sw` / `.layer`(设置)。

### ⚠️ 多个 hue 混不进一个 `var(--hue)`

个人空间的头图要表达「这个人全部作品的颜色」,但 `--hue` 是单个数值,没有办法把 N 个色相加权混成一个还保住 §4 那套 L/C 写死的层级。

实现方式是**分层叠加**:每部作品一层 `.sky-layer`,各自带独立的 `--hue` 作用域和一条径向渐变,用 `mix-blend-mode: screen` 叠出彩色分布。
**`isolation: isolate` 必须挂在容器 `.authorsky` 上,不能挂在 `.sky-layers` 上**——挂在层组上,screen 就叠不到底色 `.sky-base` 而是叠到透明,加亮效果全部消失;完全不挂,混合又会穿透到页面背景。

### 环境染色

`:root` 上另有 `--ambient-hue` 驱动整片深空背景,过渡 1.1s,回落值 **252**。**暖金不跟着变。**

| 页面 | 染色触发 |
|---|---|
| `home-galaxy.html` | 聚焦某作品时过渡到它的 hue,退出回落 |
| `community.html` | 跟随 hover/聚焦的那条事件,取**新分支侧**的 hue;离开延迟 380ms 回落(防穿过卡片间隙时闪烁);触屏无 hover,用 `IntersectionObserver`(`rootMargin: -45% 0 -45%`)取视口垂直中央那条卡 |
| `derivation-graph.html` | 跟随当前世界,包括「暂无星图」的世界 |

减动效下一律锁 252,不跟随。

## 6. 动效参数

**总原则:外壳静止,动感长在作品上,且借作品自身的主题色。** 顶栏、筛选条、缩放控件一律不动。

| 参数 | 值 |
|---|---|
| 缓动 | `cubic-bezier(.2,0,0,1)` |
| 按下 / 状态确认 / 浮层进入 / 跨屏 | 90ms / 150ms / 220ms / 320ms |
| 卡片排布切换(星系) | 1.05s,错峰 38ms |
| 卡片入场淡入(星系) | 620ms,错峰 42ms |
| 环境色相过渡 | 1.1s |
| 开屏总时长 | ≈2.6s,可跳过,`localStorage` 存**时间戳**,超过 6h 再演一遍(见 §8) |
| 星系自转 | 每帧 +0.055°,缓动逼近 `v += (target-v)*0.075` |
| 事件流筛选切换(社区) | 220ms 淡入,错峰 38ms(上限 8 张) |

### 星图动效(`derivation-graph.html`)

| 动效 | 参数 |
|---|---|
| 入场 · root 天空渗出 | `bloomIn` 1.5s |
| 入场 · 光晕群淡入 | `fadeIn` 1.2s,延迟 340ms |
| 入场 · 连线绘制 | `draw` 660ms,`pathLength=100` + dashoffset,**每层错峰 132ms** |
| 入场 · 星点亮起 | `starIn` 540ms,延迟 `层×132 + 130ms` |
| 光晕呼吸 | `opacity ×0.76→1`,`scale .95→1.06`,周期 4.4–7.0s,`infinite alternate`;**周期与相位由 hue 与序号算出**,整片不齐拍且刷新一致 |
| 待揭示节点 | 虚线环 17s 一圈自转 |
| 选中路径流光 | 9 单位亮光沿路径逐段跑,每段错峰 128ms,单程 560ms,**一次性不循环** |
| 偶发流星 | 两道,周期 11s / 14s,可见窗口仅约 1s |
| 节点 hover | 亮核 `scale(1.32)` + 变更白,180ms |

### 两条实现纪律

1. **入场动画一律 `animation-fill-mode: backwards`。** 静止态必须是「已完成」的样子(连线实线、星点不透明),动画只负责从隐藏态补进来。这样减动效禁用动画后元素落在最终态,而不是卡在隐藏态。
2. **柔光一律用径向渐变,不用 `feGaussianBlur`。** 光晕在呼吸,若模糊挂在动画元素上,每帧都要重算整张滤镜。渐变的 opacity/transform 变化只走合成,不重绘。星图现在**零 filter**。
   动画结束后摘掉 `.grow` class,不长期占用合成层。

## 7. 页面清单与逐页实现

### 导航规则（原型内部）

```text
作品入口：WANXIANG_WORK_LINK()
  ├─ radio → play-story.html?world=radio
  └─ 其他作品 → derivation-graph.html?world=<key>
```

- `derivation-graph.html` 的详情面板仅在 `radio` 上显示阅读入口；其他作品不显示假剧情。
- `season.html` 尚未实现，不得在原型中创建真实链接。

### 产品信息架构（实现遵循这一份）

```text
顶栏（4 项）      星海 /  ·  作品馆 /works  ·  我的空间 /mine  ·  社区 /community
我的空间二级导航  空间 /mine · 草稿箱 /mine/drafts · 历史记录 /mine/history
                  · 消息 /mine/inbox · 设置 /mine/settings
无入口的独立页    /story/[id] · /play/[id] · /create · /edit/[id] · /login
                  · /admin（仅 admin 角色可见入口） · not-found
```

- **顶栏是 4 项，「历史记录」不再是一级入口**——它收进我的空间的二级导航。原型顶栏那 5 项按此收敛。

### 7.5 `derivation-graph.html` — 衍生星图

> ⚠️ **产品不实现这一页,也不做「开发中」占位。** 它的前提是**跨作者衍生分叉**:无 fork 模型、无分支归属、无 `copied_from`;
> 作者侧 node CRUD 已于 2026-08-11 下线,且明令不得复用 `StoryNode`。做一个「开发中」的星图页只会让人以为 `/play` 的世界星图坏了。
>
> 下面这份规格因此是**目标形态**,等后端具备 fork 与分支计数之后才谈落地。⚠️ 它也**降级不到 `/play` 的世界星图**:
> v4 画法的核心量是「走过这条支流的人数」,而单人 session 树里每条支路的人数恒为 1,缎带会退化成等宽色带,信息量整个消失。
> `/play` 星图继续用「节点即星 / 连线即光 / 待揭示虚线环 / 确定性布局」那套——那部分视觉语言是共通的,可以复用。


**图谱就是一张星图,不是画在卡片上的树。** 直接落在深空背景上,无边框、无独立背景色;开场节点身后一片该世界 hue 的巨型径向柔光,是整页唯一的大面积色彩来源与视觉重心。

- **共享身份**:作品名、题材、hue、剪影与 `playable` 从 `assets/works-data.js` 合并;本页只保留节点树这一份专属数据。
- **单作品上下文**:当前世界只由 `?world=<key>` 决定。无参数默认 `radio`;已知但未长出岔路的 key 进诚实空态;**未知 key 进错误态**,提示「找不到这片星空」+「回到作品馆」出口,**绝不静默借用 `radio` 的内容**。
- **进入层级**:顶栏退为极低存在感的深空渐隐壳;页首先给作品名与该世界天空留白。世界类型、岔路数、最远层级、已点亮星数只作 12px 叙事元信息,不并列成数据看板。

#### 画法:不画分支,画走过分支的人

⚠️ **前三版都在画「线」,于是都撞上同一堵墙:线越多越乱,而线的多少由分支数决定。** v1 自上而下 tidy tree + 贝塞尔肘线是一张歪掉的组织架构图;v2 极坐标径向星座换了构图没换线;v3 正交折线线是干净了,可布局把**标签宽度**打进了每个节点的横向地盘,图宽 ≈ 叶子数 × 140px——50 条分支就是 7000px,适配缩放掉到 0.14×,星成灰渣、名字糊成一片。**这是结构性的,不是调参能救的。**

v4 把因果整个倒过来:

- **一条支流的宽度 = 走过它的人数。** 根占满画布高度 `H`;孩子在父亲的宽度里按人数分段。于是任意深度的总高恒等于 `H`——**构造上不可能溢出**,分支再多也一样。⚠️ 这是证明,不是调参:`H` 是定值,而每一层的分配都是对父亲宽度做划分。
- **分支之间那道暗 = 在这里停下的人。** 数据里 `Σ孩子.plays` 一直小于父亲(有人读到这里就不再往前),这个差额从来没被画出来过;现在它就是间隙本身。
- **标签只在自己那条支流够宽时才出现,写在河道内部**——**重叠在结构上不可能发生**,不需要任何避让逻辑。放大 → 河道变宽 → 名字渐次浮现,LOD 是连续的、免费的。旧版是「标签宽度决定图宽」,现在是「图宽决定哪些标签有资格出现」。
- **窄到画不成支流的并进「星尘」**,带真实计数、可点开逐条查看。⚠️ 星尘保留它们真实的宽度和,**不虚增**。
- **树向右生长**:`x` 由深度定,`y` 是自己那条河道的中心。同层按走过次数降序,最宽的放中间、其余按宽度递减向两侧交替铺,主干因此天然落在视觉中线。

#### 几条实现纪律

- **⚠️ 枝画成描边,不是填充的面。** 面会填满自己那条河道、与邻居贴边,那道「停下的人」的间隙就没了。同一个父节点的几根枝从**同一点**出发,分叉处天然是一个叉口。
- **⚠️ 枝一律等宽细线,主干与支线只差颜色、不差粗细。** 走过三版有厚度的画法都不好看,而那点信息面板里一行字就说清楚了。`vector-effect: non-scaling-stroke` 必须加:线宽活在屏幕坐标里,放大到 2.5× 时它仍是 1.35px,不会涨成一根管子。焦点环同理——2px 的环跟着视口缩就是焦点指示消失。
- **⚠️ viewBox 跟随容器像素(1 世界单位 = 1 CSS px)**,图的位置只由 `#viewport` 的 transform 决定(取自 React Flow 的 pane 模型)。让 viewBox 装下整张图再靠 `preserveAspectRatio` 缩放是**第二层看不见的缩放**:标签写 14px 实际只画出 9px,而缩放读数还理直气壮地显示 100%。
- **标签活在屏幕坐标里**:每次缩放按 `1/sc` 反补偿;出不出现由「这条支流在屏幕上够不够宽」每次缩放判一遍。不用底牌,用描边光晕(`paint-order` 让描边落在字下面)。
- **星的冷热由亮度承担,不由半径承担**;星点用 stellarium-web-engine 的 `core_get_point_for_mag` 三段式。走过次数 → 0..1 取**对数**:最热的节点是最冷的三十倍,线性映射会把其余全部压成一个点。
- **左栏层号**:一截 20px 刻线 + 两位数,停在图左侧窄栏里,**不横穿画面**——缎带本身已是一层层的横向结构,再铺一族满屏横线会和它抢读法。⚠️ 层号字号 11px / `oklch(0.68)`:它承载信息(第几层)不是装饰,9.5px / `oklch(0.54)` 在深空底上只有约 3.6:1。
- **⚠️ 命中纪律**:只有节点吃指针事件,装饰层(柔光、层号、光晕群、缎带、流光、标签)一律 `pointer-events:none`。命中区是**整段河道的矩形**,不是星那个小圆点。注意 `fill:transparent` 仍参与命中,与 `fill:none` 不同。
- **hover / 选中只加亮,前景绝不压暗**;选中那条支流的名字必然可见(整条路径挂 `.onpath`)。
- **眉标全页统一 `.16em`**——同一个角色三种字距会读成三套系统。

#### 缩略星图、面板与四态

- **缩略图画同样的缎带**(取 React Flow 的 MiniMap):一片有宽窄的光缩到 0.18× 仍然是同一个形状。视野之外用 evenodd 挖洞压暗一层,视野框用中性亮描边。⚠️ 画布只剩 560px 高时缩略图会压掉一整层节点,宁可不要。
- **面板头部是真实的天空 + 剪影**:hue 渐变天空 + 星点 + 流星 + 云 + 地平线 + 该世界姿态的剪影。人小天大——剪影靠右下,给左侧标题让出整块空间。⚠️ 正文栏宽不能取 18ch(一行只放得下 18 个汉字,末行经常剩一两个孤字);中文行高取 1.7–1.8,2.04 会把段落拆成互不相干的一行行。
- **暖金配额**:面板的主动作是全页唯一的实心暖金(第 2 处,第 1 处是品牌标记);分叉弹层里的提交因此用中性亮态。
- **图例里的枝要和图上一样是等宽描边,不是色块**——否则图例本身就在教错的读法。
- **四态** `ready / loading / empty / error` 由一个 `showState()` 统一切换并同步 `aria-busy`;渲染包在 `try/catch` 里,数据异常落错误态并带重试,不留一片空白。未知 key 落错误态但只给「回到作品馆」,不提供无意义重试。空态给「去社区看看正在分叉的世界」这个出口,不做死胡同。
- **控件状态**:缩放到上下限时按钮 `disabled`(禁用是唯一允许降低对比度的状态);缩放百分比只在**按键操作**时经 `role=status` 播报,滚轮缩放不刷屏。
- **触摸目标** ≥44px,小屏断点不得压回 40px。
- **小屏(≤900px)降级为沿主干的一维列表**:自由缩放画布在手机上不可用。⚠️ 行高取 1.5 是拉丁值,中文节点名在 360px 宽下折行后会贴到一起;每层缩进收到 10px(30px × 6 层会吃掉一半正文宽)。比例写成数字、不画长短条——桌面版的图已经不编码人数了。

### 7.6 `login.html` — 「无人之境」登录页

> 当前登录页采用「无人之境」：天空随输入进度生成，页面只保留该方向的实现规则。

- **定位**:登录不是身份校验,而是**这个世界被写出来的过程**。标题从「这里还没有故事。」变成「现在有了。」——你来之前这里是空的,是你的输入让天空长出来的。入口 hue 252,确认 hue 276,不冒充某部作品的专属天空。
- **⚠️ 核心机制:世界按输入进度逐层生成**。天空不是淡入的装饰,是由离散层级驱动的:

  | 层 | 触发 | 画面新增 | 时长 |
  |---|---|---|---:|
  | L0 | 加载 | 地平线遮罩 + **地平线余光** + 背对的 `walk` 剪影。天上什么都没有:无渐变、无云、无星 | — |
  | L1 | 邮箱 `focus` | 远层渐变从地平线升起到 `scaleY(.62)`,浓度 `.52` | 900ms |
  | L2 | 本地部分 ≥3 字符(或出现 `@` 且 `@` 前非空) | 三层云升起(仅 c1 极缓漂移);天空长到 `scaleY(.84)`、浓度 `.80` | 700ms |
  | L3 | `@` 之后开始输入域名 | 128 颗星点扫过式亮起(错峰 `(i%18)×28ms`);天空长满 `scaleY(1)`、浓度 `1`;余光退到 `.62` | 500ms |
  | L4 | 邮箱格式有效 | 天顶辉光 `.halo` 亮起(天空到此才完整);流星划过**一次**;剪影 `walk → gaze` | 1.15s |
  | L5 | 提交成功 | 暖金地平线亮起;剪影 → `reach`;hue 252→276 | 650ms |

- **⚠️ 幅度分配是这一页的成败所在,不是调参细节。** 天空的高度与浓度必须跟着层级一路增长，每层都要有可指认的新元素（云 → 星 → 辉光）；逐层对比时必须肉眼可辨。
- **⚠️ 天空渐变亮端在下、暗端在上**,与 `home-galaxy.html` 的卡片天空相反。两个理由:① 暮色本就是地平线最亮、天顶最暗;② L1/L2 是 `scaleY<1` 的稳定态,天空顶端有一条硬切边,把最暗的 `--w-sky-lo`(0.11) 放在顶端,切边与 `--bg-deep`(0.09) 只差 0.02 L,肉眼看不出;若把亮端放上面,那条边会变成一道假地平线。
- **⚠️ 地平线余光是功能,不是装饰。** 剪影 `--w-ink` 是 `oklch(0.055…)`,`.horizon` 也把地面压到同一档——**没有余光,L0 就是一块全黑的屏幕,人站在那里但谁也看不见**。做法同 `404.html` 的 `groundGlow`:一枚 `radial-gradient(closest-side,…)` 的宽扁光池,**必须叠在 `.horizon` 之上、`.figure` 之下**,压在下面会被地面遮罩吃掉。它只照地面,不构成「天空」,`L0 = 空` 的叙事不受影响。
- **本页新增两档云色 token**(挂在 `.scene` 的 `.world-scope` 上,L/C 写死只有 H 变,规则同 §4):`--w-cloud-a: oklch(0.36 0.070 H / .78)`、`--w-cloud-b: oklch(0.48 0.098 H / .50)`。§4 那两档是给小卡片设计的,铺满整屏时太暗。余光另用 `--w-ground: oklch(0.34 0.036 H / .74)` 与 `--w-ground2: oklch(0.20 0.026 H / .36)`。

- **⚠️ 单向不倒退**:JS 用 `maxLevel` 记录已达到的最高层,`reach(n)` 对 `n <= maxLevel` 直接返回。**删字只回退校验状态,不回收已生成的天空。** 否则用户改一个错字,整个宇宙就闪一下没了——而「世界一旦长出来就留着」正是这一页的主张。「换一个邮箱」同理:回到可编辑态,层级保持在 5。
- **布局(宽屏)**:场景 `position:fixed` 满屏(人小天大),表单是浮在其上的面板。面板贴右(`min(400px,100%)`,`justify-content:flex-end`),剪影与余光同锚在 `left:27%` —— 1024px 下面板起于 x=563、剪影止于 x=334,几何上不可能重叠。`.veil` 是 94° 横向读盖,**只负责保住面板区对比度,不负责把天空压黑**——首版压到 `.88` 把右三分之一压死,天空再亮也看不见逐层变化,现已放松到 `.74`。
- **⚠️ 布局(小屏)**:≤900px 时场景收成顶部条带，面板进入常规流，不再覆盖场景。`.stage` 用 `position:absolute` + `height:44vh`（≤560px 为 `38vh`），`.shell` 用 `display:block` 和 `padding-top:calc(44vh + 24px)` 把面板排在条带下方。
  - 带高改变时，场景内部的百分比定位会一起按比例重算；`.glow` 高度同步收至 `16vh` / `13vh`。
  - `.veil` 转为纵向并收至 `--bg-deep`，避免条带下沿出现硬缝；`.brandmark` 改为 `absolute`，避免滚动时压住表单。
  - ≤560px 主 CTA 保持内容宽度，不强制满宽，以避免按钮组折行；所有断点不得出现横向滚动。- **登录路径**:邮箱魔法链接,单字段。正则 `/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/`,`novalidate` 后自行校验。**无效邮箱不推进层级**,只出错误文字 + `aria-invalid`,不伪造「已生成」。提交后 650ms 忙碌态(文案换「正在开启…」,`busy` 标志锁重复提交),再在**原位置**切确认态,面板不位移。**⚠️ 忙碌态用 `aria-disabled` + `aria-busy`,不用 `disabled` 属性**——提交时焦点正在这个按钮上,真禁用会把焦点弹回 `body`,键盘用户丢失位置;拦截交给 `busy` 标志。次级出口「先逛逛」/「直接进星海」→ `home-galaxy.html`,均为文字态。
- **色彩与动效**:暖金稳定态 2 处见 §3。**L5 的暖金地平线会顶到第三处,所以确认态必须让 `form` 隐藏、主 CTA 随之退场,把配额让出来**——世界已生成,按钮就不该再抢眼。`--hue` 用 `@property` 注册后才能做 1.1s 色相过渡(不支持的浏览器跳变,不影响功能)。云的柔边用 `radial-gradient(closest-side,…)` 而非 `filter:blur` ——c1 是持续动画元素,挂 filter 会每帧重算滤镜(纪律同 §6 星图光晕)。全页零 `filter`。生成期间才给 `.scene` 挂 `will-change`,1.4s 后释回 `auto`。
- **剪影**:三种姿态同时在 DOM 里,靠 `opacity` 交叉淡入切换,不重绘 SVG。`walk` 额外 `scaleX(-1)` 表示背对。姿态由 `.scene` 上的 `pose-*` class 驱动。
- **与首页的衔接**:提交成功时写 `localStorage['wanxiang-intro-seen-v1']`(当前时间戳)。登录页刚演过一遍「世界生成」,紧接着进星海不必再播 2.6s 开屏。这是两页共用同一个键(见 §8)。
- **可达性与减动效**:触摸目标 ≥44px(input 50px / 主 CTA 50px / 文字按钮 `min-height:44px`);层级推进对读屏静音(整个 `.stage` `aria-hidden`),只有校验(`role=alert`)与确认区(`role=status`/`aria-live`)播报。**⚠️ 这两处的文案都必须由 JS 注入,不能写死在 HTML 里靠 `display` 切换**——`role=alert` / `aria-live` 靠**内容变化**触发,纯显隐在 NVDA / JAWS 上大概率不播报;`clearError()` 因此要把 `textContent` 置空,下次注入才算变化。确认后焦点移到 `.done` 容器(`tabindex="-1"` + `outline:none`),容器内有 `sr-only` 的 `<h2>进入链接已寄出</h2>`,读屏能听到上下文而不是孤零零一个按钮名。表单内文字对比度按面板半透明后的实际值核过:`::placeholder` 与 `.note` 均从 `0.60/0.58` 提到 `0.66`(约 4.3:1 → 5.7:1)。`prefers-reduced-motion` 下开页直接落在 **L4 的完整天空**(静止态即最终态,非隐藏态),禁用漂移、逐层过渡与流星,保留校验与确认态。
- **入口(原型)**:唯一入站链接是 `profile-settings.html` 的「退出登录」。原型顶栏不加登录入口——它已渲染「我的空间」(登录态),同屏再放「登录」是自相矛盾的状态。
- **⚠️ 入口(产品):顶栏最右侧是账户区,分两态。** 上面那条理由本身成立,但它**只覆盖登录态**:原型不接认证、压根没有匿名态,而产品里匿名访客可以浏览已发布作品——照原规格做,他看到的是一个**没有任何登录入口**的顶栏,只能靠点到受限页被弹走才发现要登录。改为:
  - **已登录**:头像 → 下拉菜单,**所有与「我」有关的入口都收在里面**(我的空间 / 草稿箱 / 历史记录 / 消息 / 设置,admin 另有平台设置,末尾退出登录)。将来新增个人向子页面一律加进这个菜单。
  - **匿名**:「登录」(文字态) + 「注册」(中性亮态)。
  两态**永不同屏**,原纪律照旧成立。主导航因此只剩三项公共入口(星海 / 作品馆 / 社区),**不随登录态变形**;`/mine/*` 的 SubNav 是进到那个区之后的**局部导航**,与账户菜单这个全局入口不是重复。
  ⚠️ 暖金配额:品牌圆点第 1 处、「写一个世界」第 2 处,**配额到此用满**——账户区一处暖金都不能有,「注册」用中性亮态。
  ⚠️ 登录态判定要等 localStorage 读完再渲染(`authStore.hydrated`):服务端与客户端首帧都取不到,直接按 `user===null` 画会让已登录的人先闪一下「登录 / 注册」。补水前两态都不渲染,标记一致故不会 hydration mismatch。

### 7.7 `create-editor.html` — 创作编辑器

**编辑器是一部作品的天空第一次被点亮的地方**,不是贴在深色背景上的六步表单。

- **版面**:≥1120px 为左右两栏——左 44% 是**正在成形的天空**(sticky,滚动时始终可见),右 56% 是段落轨 + 编辑面板(最大宽 640px)。≤1120px 天空降为顶部 200px 天幕条、段落轨横向化;≤720px 天幕 168px;≤560px 天幕 150px,顶栏的作品名换行独占一行。

- **⚠️ 窄屏只钉一条,钉的是段落轨,不是天空。** ≤1120px 时 `.skyside` 退回 `position:static`,`.rail` 改为 `position:sticky; top:60px; z-index:28` 并带自己的毛玻璃底与全宽出血(`margin:0 -18px`,≤560px 为 `-14px`)。
  理由:窄屏钉不下两条,而**天空是反馈、轨是导航**——写到一半时能切段比能看见天空更要紧;天空滚一下就能回看。
  段落轨必须保持 sticky；静态定位会让用户滚动后失去步骤导航。

- **⚠️ `.editor` 在 ≤1120px 必须退成 `display:block`,`sticky` 才有行程。**
  `position:sticky` 挂在 grid item 上时,**包含块是它自己那一行**。单列布局下行高就等于轨自身的高度,行程为 0,`top` 写什么都钉不住——第一次改成 sticky 时正是栽在这里,轨照样滚走。桌面端能钉住纯属侥幸:轨与面板同一行,行高由面板撑开。
  **凡是把 sticky 用在 grid / flex 子项上,先确认它那一行(或那条主轴)比它自己高,否则等于没写。**

- **⚠️ 窄屏的段落轨是 6 等分网格,不是横滑胶囊条。** `grid-template-columns:repeat(6,minmax(0,1fr))`,序号在上、名称在下,副标题隐藏。
  六段是**固定的六个**,应当一眼全见。窄屏使用固定六列而非横向滚动；每格 ≥52px 高，360px 下约 50px 宽。

- **⚠️ 段落轨是静态标记,不是 JS 建出来的。** 六个站点写死在 HTML 里,`renderRail()` 只改 `data-state` / `aria-current` / 序号字符,不重建 DOM。
  这是 §6「静止态必须是已完成的样子」在导航骨架上的同一条纪律:**导航不该依赖脚本才能存在**。附带好处是每次渲染不销毁按钮,焦点不会掉。
  配套的是启动兜底——启动段包在 `try/catch` 里,失败时显示 `#bootFail` 说明块(含真实错误信息与「清空本地草稿并重试」),而不是留一个看不出哪里坏了的半死页面。

- **⚠️ 导航用事件委托,且在脚本最上方注册。** `[data-go]` / `#btnPrev` / `#btnNext` 由一个挂在 `document` 上的委托监听处理,写在 IIFE 开头、**先于任何可能抛异常的代码**;`go()` 内部把面板切换与按钮禁用放在最前,`renderRail()` 与焦点各自兜底。
  代价换来的是:中途任何一组绑定抛异常,导航都不受影响。**静态轨解决「看不见」,委托解决「看得见但点不动」——这两件事必须一起做**,否则加固只是把一种故障换成另一种更难懂的故障(轨在那儿,点了没反应)。
  另加 `window.addEventListener('error', …)`:任何未捕获异常都会摊进 `#bootFail` 面板,不再只躺在控制台里。

- **⚠️ 天空即完成度**:进度不由进度条表示,**进度就是那片天空**。六段各点亮一层,层与段一一对应:
  | 段 | 就绪判定 | 点亮的层 |
  |---|---|---|
  | 1 灵感 | 钩子 ≥8 字 且 已选题材 | 地平线 |
  | 2 世界观 | 背景 / 基调 / 规则三项非空 | 渐变天空 + 环境星点 |
  | 3 属性 | ≥1 个属性且无重名 / 空名 / 数值型非数字 | **属性星** |
  | 4 开场 | 正文 ≥40 字 | 剪影落位 |
  | 5 天空 | 主题被显式选过 | 云层 + 流星痕 |
  | 6 发布 | 体检全过 | 一道流星(一次性,减动效下不播) |
  段落**可任意跳转,不强制线性**;某段没写完,天空就缺那一层——不需要读错误列表才知道。

- **⚠️ 每一层单独看都必须有肉眼可辨的变化**。按下表实现各层，避免新增层与底层亮度过近。
  | 层 | 首版的问题 | 现在的值 |
  |---|---|---|
  | L1 地平线 | 用 `--w-ink`(0.055)压在 0.075 的底上,ΔL 0.02 = 没画;还把剪影一起吃掉 | 改成**地平线辉光带**:`oklch(0.50 .100 h /.42)` → `.40` → `.22` → ink 的四档渐变。真实天空本就地平线最亮,合成后 ΔL≈0.18,且给纯黑剪影一个站得住的背衬(同 `404.html` 的 `groundGlow` / 登录页的地平线余光) |
  | L2 环境星点 | 30 颗 × 1.5px 撒在整块预览上,肉眼无感 | **120 颗 × 1.9px**(22% 放大到 2.7px),线性同余种子 9301,刷新一致 |
  | L4 剪影 | 黑剪影压在同样近黑的地面上 | 由 L1 的辉光带背衬,ΔL≈0.20 |
  | L5 云 | 用 §4 的 `--w-cloud`(0.20)压在 `--w-sky-md`(0.22)上,负对比 | 页面内改用 `oklch(0.40 .080 h /.58)` 与 `oklch(0.52 .090 h /.44)`,并**把云移到中段天空**(`bottom:44%` / `56%`),底部让给辉光与剪影。合成后 ΔL≈0.12 |
  属性星(L3)是**语义元素**——一个属性一颗,数量由作品决定,不能为了「够亮」注水。因此改的是单颗的可见性:核 3.4px→4.4px,双层光晕;待亮环 11px→13px、描边加粗并补一层极弱内晕。

- **属性星的三态映射**(与星图语言一致):可见属性 = 一颗亮星;`reveal`(渐显)= 不发光的虚线待亮环,17s 自转;`hidden`(仅 AI 可见)**根本不上天**,只在字段旁注明。星位是**横向等分列 + hue 决定纵向**的确定性布局,不用 `Math.random()`;标签限宽可换行,长属性名不会顶出画面,也不靠 `overflow` 掩盖。

- **段 4 写在真实阅读层上**:身后是这个世界的天空,正文坐在阅读遮罩上,字号 17px / 行距 2.05,与 `play-story.html` 一致。**遮罩浓度下限锁 0.52**(代码里是 `readerPrefs.SCRIM_MIN = 52`,百分比整数)。滑杆在「试读」弹层里。

- **段 5 主题 = id 映射表**:落库的只有 `world_config.theme` 一个 id,hue 与剪影姿态由前端注册表查出。**因此色相是 8 选 1,不是连续转盘**——这是拿「零后端改动」换来的。注册表见下表(§8 已收录):
  `star` 252 gaze · `radio` 238 radio · `ink` 196 umbrella · `xian` 168 blade · `heal` 132 reach · `horror` 96 walk · `sci` 312 walk · `love` 340 gaze。
  hue 全部取自已交付页面验证过的 12 个值,不新造;六种姿态覆盖八个 id,`star`/`love` 与 `horror`/`sci` 各共用一个姿态,两对色相隔得远不会认混。
  封面默认就是这片天空;可选上传一张图覆盖,**图上仍压一层主题渐变罩层**保住标题对比度,前端等比缩到最长边 1280 导出 webp q0.85(本原型仅本机预览,未接上传接口)。

- **段 6 发布体检**:12 条检查逐条列出,未过的带「去修」直接跳到出问题的段并聚焦该字段。**实心暖金主 CTA 只此一个**,未过时 `disabled`。`attributes` 与 `initial_state` 在 UI 上是同一行的两个格子,**结构上不可能不对应**,所以那条后端校验规则恒为通过。发布成功后给落地说明,**不做跳转**——「我的创作」还没建成。

- **不提供节点树编辑器**:后端节点 CRUD 已整组下线,剧情树是游玩时长出来的。做树编辑器会与产品模型冲突。

- **AI 起草槽**:每段留有起草入口与候选契约说明——**候选必须显式「采纳」才写入字段**,未采纳不进作品、不进天空、不进草稿。⚠️ **「接口尚未接入」已过期**:`/assist/world`、`/assist/opening`、`/assist/polish` 三个都已上线并在编辑器里用着(经 Go `/api/v1/assist/*` 转发,前端不直连 agent);只有 `/assist/branches` 未接。润色走「候选预览 + 显式采纳」,与上面这条契约一致。

- **草稿**:全量状态写 `localStorage`(键 `wanxiang-editor-draft-v1`),输入后 700ms 防抖自动保存,保存状态由顶栏 `role=status` 播报。接后端前它只存在于这台设备。

- **无障碍**:段落切换后焦点移到该段 `h2`(`tabindex="-1"`);重建控件后焦点放回刚操作的那一个(题材 chip、主题色块、属性类型选择器);触摸目标全线 ≥44px;试读弹层 Esc 关闭、Tab 回环、关闭后焦点归位;`prefers-reduced-motion` 下取消点亮过渡、虚线环自转与流星,静止态即最终态。

### 7.8 `profile-space.html` — 我的空间(主页)

- **共享身份与入口**：原创与收藏卡通过 `WANXIANG_WORK_LINK()` 按作品能力跳转。

- 原创作品与收藏行使用 `WANXIANG_WORK_LINK()`；可游玩的电台进游玩页,其余作品进入对应星图。
**一个人的主页不是资料卡片墙,是一个人的星域。** 因为每部作品自带 hue,一个创作者的全部作品天然就构成一片有色彩分布的小星群——这一屏最该做的事,是让人一眼看出「这个作者是什么颜色的」。

- **作者的天空(340px)**:不用头像圆框。基底是这个人的主色相,上面叠 N 层柔光,每层是他一部作品的 hue(见 §4「多个 hue 混不进一个 `var(--hue)`」)。云、星点、流星痕压在柔光之上,地平线与剪影再压在最上。剪影 88px、贴右 26%,铭牌锚左下角四边等距 22px,**两者不重叠**。
- **视角双态**:右上角是**原型态**的视角开关(本人 / 访客),如实标注为「原型视角」,不伪装成产品功能。状态写 `localStorage`(键 `wanxiang-profile-space-v1`)。
  | | 本人视角 | 访客视角 |
  |---|---|---|
  | 主动作槽 | 「继续那 N 片没写完的天空」→ 草稿箱 | 「关注」(点后退成描边中性态) |
  | 次动作 | 编辑资料 | 从 TA 的世界分叉 → 社区 |
  | 创作者工作台 | 显示(草稿箱 / 消息 / 设置,带计数) | 隐藏 |
  顶栏的「写一个世界」在两态下都是描边次级入口,与主动作槽是**不同的动作**(新建 vs 续写),不构成重复 CTA。
- **身份行不做数据看板**:关注数、被分叉数用 12.5px Inter 压到副信息层级,与自述同一区块内联排布。**不做 KPI 卡片行**——那是 SaaS 语言,不是这个产品的。
- **三条脉络**(`role=tablist`,←→ / Home / End 可走):
  1. **原创作品** — 作品卡网格,每张自己的 hue 天空 + 剪影 + 状态角标(连载中 / 已完结),角标锚右上角、与铭牌同一内边距。这条脉络就是原先规划的「我的创作」。
  2. **衍生贡献** — 这是《万象》区别于普通个人页的关键,给它与原创同等权重。见下。
  3. **收藏** — 单列列表,62px hue 缩略天空 + 剪影。文案明确「收藏不发通知,也不计入任何人的排名」。
- **衍生贡献 = 内嵌的星图片段**:一张 `840×330` 的 SVG,三个母世界各一簇局部星图(`translate` 到 `ox` 0 / 288 / 566),**坐标手写、确定性**,不用 `Math.random()`。这个人写的节点用 `--w-kick` 实心 + 一圈细环 + 加粗连线 + 常显标签,原作节点用 `--w-star`。点星 → 右侧 `role=status` 读出区给「引句 → 来处 → 事实 chips → 去完整星图」。
  **命中纪律照搬 §7.5**:`.edges` / `.halos` / `.tag` / `.wlabel` 一律 `pointer-events:none`,SVG 里只有 `.node` 子树吃指针事件,靠 `fill:transparent` 的 `.hit` 圆(r=24,即 48px 触摸目标)工作。节点是 `role=button` 的 `<g tabindex="0">`,Enter / Space 激活。
- **资料真源**:名字、用户名、自述、主色相、剪影姿态从 `localStorage` 键 `wanxiang-profile-v1` 读出(由 `profile-settings.html` 写入),缺省回落到内置值。因此改完设置回到这一屏,天空真的会变。
- **≤980px** 衍生贡献的读出区从右侧栏落到星图下方;**≤820px** 头图降到 300px、剪影移到右 12%,铭牌改为整宽;**≤560px** 头图 268px、作品网格最小列宽 150px、收藏行隐藏时间尾列。
- 原创与收藏均带空态(带出口,不做死胡同)。

### 7.9 `profile-drafts.html` — 草稿箱

**进度不是一条百分比,缺哪一段就真的少哪一层天空**——与 `create-editor.html` 的「天空即完成度」同一套语言,判定函数 `ready()` 与 §7.7 那张表**逐条同源**。

- **缩略天空(150px,4:3)**:只画点亮的层。段 2 没写就没有 `.l-sky`(渐变天空整层缺席),段 4 没写就没有剪影,六段全空时显示「还是一片黑」。属性星只画非隐藏属性——`hidden` 属性**根本不上天**,与星图和编辑器一致。
- **六层轨**:六个 chip「段名 · 层名」,亮起的用中性亮态实心点,未亮的用空心描边。
- **「接着写」条**:整页唯一的实心暖金,指向最近改过的那一份,并写明「天空点亮 n/6 层,下一步是段 X『名字』——还缺某某层」。列表行的「继续」一律描边中性态,因此同屏永远只有一个实心按钮。
- **真实草稿优先**:读 `localStorage` 键 `wanxiang-editor-draft-v1`(编辑器的真源),存在则排在最前并打「本机草稿」标记。其余为演示数据,页脚**如实写明**「编辑器目前只保留一份正在编辑的草稿,多于一条的部分是演示数据」。演示草稿的删除状态存 `wanxiang-drafts-demo-v1`。
- **删除确认**:模态框,Esc 关闭 / Tab 回环 / 关闭后焦点归位,删除后焦点移到列表里的下一个删除按钮。破坏性确认键用中性亮态,不占暖金。
- **≤640px 重新编排**:三栏改为纵向,缩略天空转成 16:7 的整宽天幕带,工具行横过来——不是把桌面版压扁。

### 7.10 `profile-inbox.html` — 消息与互动

- **共享身份与入口**：消息按作品名查找共享作品；续写非 `radio` 时 CTA 明示「看星图」，不再错误跳固定游玩页。

- 带 `w`（作品名）的事件在渲染前用共享数据解析 hue 与链接：不再出现《蝉鸣停止的那天》或《深潜者笔记》误跳到电台游玩页的假入口。
**只有真的发生过的事**:分叉、续写、改写、关注、系统。**不做点赞、徽章、等级。**

- **筛选条**(sticky,顶栏下 76px):六段——全部 / 开新分支 / 续写节点 / 世界被改写 / 关注 / 系统,每段带未读计数。类型与 §8 的衍生事件契约 `EVENT.t` 同源。
- **头像是剪影 + hue 天空圆(44px)**:背景用 `--w-halo → --w-sky-hi` 两档较亮的天空,保证纯黑剪影在小尺寸下仍读得出轮廓(与 §7.4 创作者轨道同一处理)。系统消息用品牌标记,不用剪影。
- **未读标记用中性亮态**,左侧 6px 圆点 + 卡片背景抬一档。**这一页不用满暖金配额**,只有品牌圆点一处。
- **已读是三态**:`1` = 手动已读,`-1` = 手动标回未读,缺省 = 消息自带的初始状态。只存布尔会让「把已读标回未读」在本来就是已读的消息上失效。存 `localStorage` 键 `wanxiang-inbox-v1`。
- 「全部标记已读」在无未读时 `disabled`(禁用是唯一允许降低对比度的状态)。筛选切换通过 `sr-only` 的 `aria-live` 播报结果条数。
- 每种筛选都有独立空态文案,不是一句通用的「暂无数据」。

### 7.11 `profile-settings.html` — 资料与设置

- **左表单 + 右预览(316px,sticky)**:预览就是「别人打开你的空间时看到的第一屏」,改名字、改色相、改姿态都实时反映。≤900px 预览挪到表单**前面**变成 190px 天幕带(`order:-1`),不是把双栏压扁。
- **色相是 15 个预设色块 + 一条自由色相条**(原规格是「8 选 1 不是连续转盘」,已随 §8 主题一节推翻):预设只是便利项,落库写的是 `{hue, figure}` 值。色块是 hue 天空小片 + 地平线,选中态用中性亮态描边 + 内阴影。姿态 6 选 1,来自 §8 的剪影 API。**不用原生 `<select>`**(Windows 原生下拉的白色区域会毁掉深底)。

- **重建控件后焦点归位**:点主题色块 / 姿态会重绘整组,重绘后焦点放回刚选中的那一个。
- 账号区的邮箱为 `disabled` 回显,身份服务未接入前不可改;「退出登录」指向 `login.html`，这是全站唯一指向登录页的链接。

### 7.12 `404.html` — 掉出星空

**404 不是错误提示,是一次坠落。** 在《万象》的世界观里,一个空地址不是 bug,是一片还没被点亮的空——这是全项目唯一能把「找不到」写成叙事的地方,所以它不用大字号「404」+ 灰色 Oops。

- **不属于任何世界**:`--ambient-hue` 锁死回落值 **252**,场景的 `--hue` 同样固定 252。理由与 `login.html` 同源——借某部作品的天空就是撒谎。因为 hue 永不变化,SVG 渐变的 `stop-color` **直接写字面 oklch(…252…)**,绕开 §4 那条「`var()` 在声明处完成替换」的陷阱;非渐变的描边/填充仍走 `.world-scope` 变量。
- **版式 = 左文 · 右景**：
  `.shell` 是 `max-width:1180px` 的 flex 行,`.copy`(`max-width:480px`)与 `.scenecol`(`flex:0 0 46%`)是**兄弟节点,几何上不可能重叠**——这是本页不用任何 z-index 博弈就守住版面完整的原因。整页高 `calc(100dvh - 74px)` 垂直居中。
 - **≤980px** 塌成单列,`.scenecol` 用 `order:-1` 提到文字前面(先看图,再读字),场景宽 ≤420px;**≤640px** 场景 ≤330px、三个出口整宽堆叠。
- **场景 = 熄灭的星 × 断掉的航迹**(viewBox `0 0 700 660`,**竖向构图**:天在上、人在下,整块 `aria-hidden`,语义全部由 h1 与正文承担):
  - **熄灭的星**在上方 `(486,150)`:空心虚线双环(r 40 / 24)、**不发光**、56s 缓慢自转,与 §7.5 星图的「待揭示节点」是同一形态。它是全页唯一不亮的星,信息量全在这一点上。
  - **航迹**从画面外左下 `(-24,626)` 升起,经三个**已点亮的航点**,在抵达那颗星之前由渐变散掉(`stop-opacity` 在 82% → 100% 归零),末端停在 `(452,268)`,与星之间留约 120 单位的空白让眼睛自己补完。读作「你确实走过这些地方,但路到这里断了」。
  - **⚠️ 三个航点必须是路径自身的锚点**:`(190,552)` / `(300,480)` / `(378,392)` 正是那条 `C` 链的段间锚点,所以永远贴在线上。目测放点、或改路径后忘了同步点位,会出现「亮点浮在线外」——那是这张图唯一会露馅的地方。
  - **地平线余光**:一片 hue 252 的径向柔光压在地平线 `y=590` 上。它存在的唯一理由是**让纯黑剪影读得出轮廓**——本页没有渐变天空,不给这层光,`--w-ink` 剪影会直接消失在深空底里。
  - **剪影**用 `gaze` 姿态,站在地平线上仰头看那颗不亮的星,`x=396 y=529`,76×70px,约占场景高度 **10.6%**(人小天大)。它落在航迹**右下方**、星的正下方:早先把它放在 `x≈300` 时头顶离航迹只有 10 单位,视觉上会粘在一起。
- **⚠️ 场景 SVG 必须 `overflow:hidden`**:航迹起点在 `x=-24`、地平线余光在 viewBox 之外。若按常见做法开 `overflow:visible`,那片柔光会漏出场景**渗进版心**。裁切后余光取 `cy=584 / ry=70`,使它正好在底边 `y=660` 之前衰减为 0——否则裁切处会留一条硬边。航迹被裁在 `x=0` 无所谓,那一段的渐变透明度只有 .08。
- **⚠️ 标题的换行是排过的**:`h1` 拆成两个 `display:block` 的 `<span>`——「这片坐标上,」/「还没有星。」(6 字 / 5 字)。交给自动换行,在 480px 的窄栏里第二行只剩 2 个字,是 §9 明令禁止的孤行。
- **出口三个,实心只有一个**:「回到星海」是全页唯一实心暖金;「去作品馆找找」「去社区看看」一律描边中性态。三者是三个不同的去处,不是同一动作重复三次。后两条标签**刻意取同样长度的平行句式**,好让三个按钮在 445px 的栏宽里排成完整一行,不折成 2+1。
- **动效**:航迹 `stroke-dashoffset` 一次性绘制 1.5s(不循环),三个航点在 0.42s 后每隔 0.30s 依次淡入;星自转常驻。绘制结束后把临时 `will-change` 释回 `auto`。
  - **减动效**:直接跳终态——航迹完整、航点可见、星静止。航点的 CSS 默认值就是 `opacity:1`,淡入由脚本反向接管,因此**脚本不执行时也是终态**,不会留下一张空图。
- **无入口,只有出口**:不进任何页面的顶栏(见 §7 导航图下的说明)。顶栏本身保留,但不带 `aria-current`——404 不是一个导航目的地。
- **如实说明**:页脚写明这是静态原型、没有服务端路由,真实部署时把服务器的 404 指向本页。不假装这一页已经被真正接上。样式是一条细线上的小字,**不是一个方盒子**——它是脚注,不该在版面上占一个块的分量。
- **响应式**:≤980px 单列 + 场景前置;≤640px 品牌英文名隐藏、出口整宽堆叠、场景 ≤330px;≤400px 顶栏的「我的空间」隐藏(`data-secondary`)。无横向滚动。

### 7.13 `reading-history.html` — 历史记录

- **共享身份与入口**：接着读、标题链接与操作 CTA 都走 `WANXIANG_WORK_LINK()`；非可游玩作品使用「看星图」文案。

- 最近记录、列表标题与行内操作均用 `WANXIANG_WORK_LINK()`；非可游玩的演示记录显示「看星图」并进入相应 `?world=<key>`。
**历史不是一张「读过什么」的清单,是你留在别人世界里的航迹。** 顶栏进入历史记录页，继续阅读由页内操作决定。

- **机制:走过几个航点。** 每条记录右侧是一条四航点的航迹,对应 `play-story.html` 的 `TOTAL_STEPS = 4`。走过的航点是实心亮星 + `--w-glow` 柔光,没走的是**空心虚线环、不发光**——与 §7.5 星图的「待揭示节点」是同一形态。段间连线同理:走过的是 2px 的 `--w-line` 实线,没走的是 1px 的中性细线。
  与 `profile-drafts.html` 的「六层天空 = 创作完成度」同族但**不是同一个机制**:那边缺的是天空的层,这边缺的是航迹上的点。写作看完成度,阅读看走了多远。
- **缩略天空(176px,4:3)**:hue 天空 + 22 颗星点 + 两层云 + 地平线余光 + 剪影。**只有走完(有结局)的世界才划流星**——流星是「这条路走到头了」的标记,不是装饰。
  ⚠️ 逐层可辨(§4 的 ΔL ≥ 0.10):云用页面内的 `--w-cloud-a` `oklch(0.40 .080 h /.58)` / `--w-cloud-b` `oklch(0.52 .090 h /.42)`,**不用 §4 那个会比天空还暗的 `--w-cloud`**;星点 2px(不是 1.6px);`--w-ground` `oklch(0.50 .100 h /.44)` 的地平线余光是纯黑剪影唯一的背衬光源,做法同 `404.html` 的 `groundGlow`。星点位置走线性同余伪随机(种子由 hue 算出),**不用 `Math.random()`**,刷新后位置不变。
- **剪影在缩略图里的比例**:28px(小屏天幕带 34px),约占缩略图高度 **17%**(小屏约 24%)。§9 的「剪影 <15%」约束的是主场景构图;缩略图受最小可读尺寸限制做不到,这里取的是**比 `profile-drafts.html`(34px / ≈112px ≈ 30%)更克制**的一档,如实记录而不是宣称达标。
- **页脚小字用 `oklch(0.66 0.018 265)` 而非 `--muted-2`(0.60)**:压在深底上约 5.7:1,同 `login.html` 那轮的对比度修正。列表行标题的 hover **只加下划线不动前景色**——前景对比度不得低于默认态。
- **「接着读」条**:整页唯一的实心暖金,指向最近一条**还没走完**的记录;全部走完时整块隐藏(配额降为 1 处)。列表行的「继续 / 重读」一律描边中性态,因此同屏永远只有一个实心按钮。
- **真实存档优先**:读 `localStorage` 键 `wanxiang.play.midnight-radio`(`play-story.html` 的真源),存在则用它覆盖《最后的深夜电台》那条的**航点数**(`path.length + 1`,上限 4)与**停下的那句话**(`log` 里最后一条非 `sys` 段落的 `t`),并打「本机存档」标记。其余七条是演示数据。
  页脚**两态如实说明**:有真实存档时写明哪一条是真的、其余是演示;没有存档时直接写「这一页现在整屏都是演示数据」。不含糊其辞。
- **筛选**:全部 / 还在走 / 已抵达结局,三段带计数,选中态中性亮态。每段有**独立空态文案**,不是一句通用的「暂无数据」。筛选与删除状态写 `localStorage` 键 `wanxiang-history-v1`。
- **删除是两个动作,共用一个弹层**:单条「擦掉这条航迹」与「清空历史记录」。文案都写明**游玩存档不会被删**——这一页删的是记录,不是进度。Esc 关闭 / Tab 回环 / 关闭后焦点归位,删完焦点移到列表里的下一个删除按钮。破坏性按钮用中性亮态,不占暖金。无记录时「清空历史记录」`disabled`。
- **统计行由数据算出**:走进过 N 个世界 / 抵达 M 次结局 / 最远走到第 X 章,**不写死**,删除后立即重算。不做 KPI 卡片行。
- **h1 的换行是排过的**:拆成两个 `display:block` 的 `<span>`——「你走过的天空,」/「都还留在那里。」(7 字 / 6 字),避免窄栏里第二行只剩 1–2 字的孤行。
- **≤640px 重新编排**:三栏改纵向,缩略天空转成 16:7 的整宽天幕带(剪影同步放大到 44px),工具行横过来,航迹条放开宽度上限——不是把桌面版压扁。
- 筛选与清空走 `document` 上的**事件委托**并注册在 IIFE 最前(§7.7 那条纪律),中途任何一段抛异常都不会让筛选变成「看得见点不动」。

### 属性三态(对应后端,UI 必须体现区别)

- 类型:`number`(累加)/ `scalar`(覆盖)/ `set`(增删)
- `hidden` = **仅 AI 可见,玩家永不显示**
- `reveal` = 剧情揭示后才显示

### 主题:值随作品落库(不是 8 选 1 的 id)

⚠️ **本节原先规定「落库只存注册表 id、hue 由前端查表得出」,该规格已被推翻。**
理由不成立:`world_config` 是 JSON 列且未知键原样透传,存连续色相同样是零后端改动;而 id 方案有个实打实的坏处——预设只是前端常量,改动 `ink` 的色相会让所有用它的作品**一起变色**。颜色应当是作品身份的一部分,不能在作者背后漂移。

**落库格式**(两种形态长期并存,不是待清理的历史包袱):

```json
world_config.theme = "star"                            // 旧数据:查预设表
world_config.theme = { "hue": 214, "figure": "gaze" }  // 现在:值内联
```

**读取**走 `lib/hue.ts` 的 `resolveTheme(worldConfig, storyId)` 三级解析:对象直接用 → 字符串查预设 → 缺失则 `storyId` 哈希派生 hue、姿态默认 `gaze`。**写入**一律写成对象,选了预设也把值固化,不写 id。

下表因此**降级为选色器的便利项,不再是存储格式**;并已从 8 套扩到 15 套——原 8 套有 6 套挤在 96–252 的冷色区,0–90 的红橙琥珀整段空白,而星系把所有作品的天空并排铺开,这个偏斜一眼就能看出来。

⚠️ **预设变多不等于星系变花**:作者若一路回车选默认,星系照样单色。真正起作用的是两条——段 5 **不预选任何主题**(作者必须显式选过才算就绪),以及 `star` 的标签**去掉「默认」二字**(叫默认就是在告诉作者「不用管这个」,它会吃掉大部分作品)。

### 剪影 API

`figure(type)` 返回 SVG 字符串,`viewBox="0 0 100 92"`,`fill/stroke: currentColor`(由 `--w-ink` 着色)。结构 = 头(circle)+ 躯干(path)+ 四肢(stroke path,`stroke-linecap:round`)。

## 9. 硬约束(交付前逐条过)

### 视觉方向
- [ ] 深空墨底,非纯黑;出现白底一律视为跑偏
- [ ] 每部作品的 `--hue` 真实驱动配色,不是手调的固定色
- [ ] 剪影纯黑无细节,占画面 <15%
- [ ] 暖金每屏 ≤2 处且不参与 hue 染色

### 颜色与 token
- [ ] 角色 token 声明在**使用它的元素**上,不在 `:root`
- [ ] 派生色一律 `oklch()`,文件内无 hex 色值
- [ ] 每个角色 token 的 L / C 固定,只有 H 变

### 排版
- [ ] CJK 标题行高 ≥1.3、`letter-spacing: 0`
- [ ] 正文无 `text-align: justify`
- [ ] 两族字体分工不混
- [ ] 任何语言下末行不留 1–2 个孤字;不用 `overflow:hidden` 掩盖

### 交互态
- [ ] hover 改背景/描边/阴影,**绝不**把前景改暗或改成 muted
- [ ] 交互态前景对比度不低于默认态(disabled 是唯一例外)
- [ ] 每个可聚焦元素有可见 `:focus-visible` 环
- [ ] 浮层可 Esc 关闭,Tab 在内回环,关闭后焦点回到触发元素
- [ ] 同一动作全站只有一个实心主 CTA;相邻按钮组最多一个实心

### 无障碍
- [ ] `prefers-reduced-motion` 下无位移/缩放/循环动画,且静止态是最终态而非隐藏态
- [ ] 正文对比度 ≥4.5:1;大字与图标 ≥3:1;阅读态遮罩浓度 ≥0.52
- [ ] 图标按钮有 `aria-label`,装饰图标 `aria-hidden`
- [ ] 触摸目标 ≥44px
- [ ] 图标一律 1.6–2px 单线 SVG + `currentColor`,**禁用 emoji 当图标**

### 响应式
- [ ] 360 / 768 / 1024 / 1440px 均无横向滚动
- [ ] 小屏是重新编排,不是把桌面版压扁

### 性能
- [ ] 无限循环的动画只改 opacity / transform
- [ ] `filter` 不挂在持续动画的元素上
- [ ] 动画结束后释放 `will-change` 与临时 class

### 命中测试(SVG 交互页专用)
- [ ] 装饰层一律 `pointer-events:none`,只有可交互元素吃指针事件
- [ ] 叠在可点元素**上方**的任何层(标签、流光、遮罩)都已确认不拦截点击
- [ ] 拖拽有位移阈值,轻微抖动不会把点击吃成平移
- [ ] 拖拽状态在 `pointerup` / `pointercancel` / `lostpointercapture` 三处都会复位

## 10. 交付边界与待接入

以下是前端实现时必须如实保留的当前边界，不是开发日志：

- **登录**：`login.html` 的确认态是原型，不发邮件、不建立会话；接认证服务时替换提交回调与确认文案，不改天空生成机制。
- **作品数据**：个人空间、消息、阅读历史的大部分内容是演示数据；页面已用文案说明，接后端前不要伪造成真实多用户数据。
- **草稿与分叉**：编辑器只保存本机草稿；社区与星图创建的分支不能直接载入编辑器，确认文案必须持续说明这一点。
- **游玩范围（原型）**：原型里只有《最后的深夜电台》有真剧情，其他作品只能进自己的星图。**产品无此限制**——`/play/[sessionId]` 对任何已发布作品都成立。
- **阅读历史（原型）**：仅《最后的深夜电台》读取真实本机存档。产品读 `GET /play/sessions`。
- **响应式回归**：实现或改版后必须在 360 / 768 / 1024 / 1440px 复核无横向溢出、无重叠、无裁切；星图在 ≤900px 使用树列表，星系在 ≤820px 使用 2D 天空墙。
- **规模化预留**：现有 12 部作品适合当前星系排布。⚠️ **星图那一侧的规模问题已由 §7.5 的 v4 画法在构造上解决**（总高恒等于画布高，分支再多也不溢出；标签只在河道够宽时才出现，重叠不可能发生），不需要「重新评估节点避让」。仍要评估的是**列表渲染**：`/works` 目前一次拉 100 部在前端筛，`meta.total > 100` 是把搜索/筛选/排序/分页下沉到后端查询参数的触发点。
- **未实现页面**：赛季共创征集仍无 `season.html`，不得在产品中添加跳转入口。
