STORY EDITOR · 设计系统 v1

一套 token，两种态,贯穿创作与游玩

共享地基(字阶 / 间距 / 圆角 / 动效 / 可访问性)之上,叠两个主题层:管理态供编辑器、社区、书库、设置使用;阅读态只留给游玩页。编辑器与社区同属管理态,因此天生统一。

设计原则 · 双态

先判断这一屏属于哪个态,再取对应 token。绝大多数产品界面是管理态;只有正文游玩沉浸场景用阅读态。

管理态 · Product 浅色

  • 用途:创作编辑器、社区、书库外壳、个人设置
  • 白底 + 中性灰阶,--accent 蓝克制点缀(每屏 ≤2 处)
  • Inter 无衬线,8px 圆角,1px 边框
  • 目标:清晰、可扫、结构化

阅读态 · 沉浸

  • 用途:仅游玩页正文体验
  • 暖深色 + 阅读遮罩,暖金 --accent-read 单点缀
  • Noto Serif SC 衬线正文,昼/夜 + 场景 token
  • 目标:专注、代入、字是主角

动效

动效只用于「确认已发生的状态变化」,非微交互一律 <500ms。统一缓动 cubic-bezier(.2,0,0,1)。全部尊重 prefers-reduced-motion。悬停我这张卡试试。

按下 90ms 状态确认 150ms 浮层进入 220ms 跨屏 / 容器 320ms

动效落位原则:外壳静止,动感借内容主题色

不给外壳(导航 / 白底 / 搜索)加动效——那会引入一种统一动效「风格」,与冷静画框冲突。动感只长在作品上,且每处动效借用该作品自己的主题色,于是天然千卡千面,成为「无穷创意」的延伸而非敌人。仅用于书库 / 发现等内容墙,不用于工具型界面。

  • 入场错落:卡片进入视口时淡入+上浮(500ms,错峰 ≤385ms),一次性;IntersectionObserver 触发后 unobserve,动画结束清理类,不残留。
  • 悬停即主场:浮起 + 封面高光扩散 + 浮现「开始阅读」(180–250ms)。动效预算优先花在功能性反馈上。
  • 活封面:主题渐变 16s 极慢漂移,各卡错开相位,借作品自身两色——「作品的氛围在动」,非全站统一特效。
  • 签名微交互:游玩数 count-up、Hero 强调词渐变流动。全站保留一个「让人记住的微动作」即可,不堆叠。
  • 减动效兜底:所有位移/缩放/循环动效在 prefers-reduced-motion: reduce 下停用,内容直接呈现(CSS + JS 双保险)。
  • 循环动效红线:活封面/流动等 >5s 的 loop,长期需配全局「减少动效」开关以满足 WCAG 2.2.2;闪烁 ≤3 次/秒(2.3.1)。

按钮

层级:主(黑) > 强调(蓝,高信号动作) > 次级(描边) > 幽灵。危险动作用 danger。每屏一个主按钮。含 hover / active / focus / disabled。

背景层架构(为「自主背景」预留)

自传背景图暂不实现,但架构已就绪——留好替换点与可读性护栏,后续接入只需填三步,无需改动排版与配色。

  • 三层顺序(自下而上):① 背景层 .bg → ② 阅读遮罩 .scrim(半透明托底)→ ③ 正文。正文永不直接贴背景。
  • 预留替换点:背景层图源走单一变量 --reader-bg(默认=内置 CSS 场景)。接入上传时只需把它覆盖为 url(用户图),其余不动。
  • 可读性护栏(硬约束):遮罩浓度 --scrim-alpha 下限锁 .52;背景层再叠一层随浓度联动的整体压暗。任意用户图 → 正文对比度稳定 ≥ AA。
  • 接入三步:① 加 <input type="file" accept="image/*"> 上传控件;② URL.createObjectURL 赋给 --reader-bg;③ 真产品里存 world_config / 会话级并回填。含「移除/复位默认场景」。
  • 边界:仅阅读态启用;管理态(编辑器/社区)不引入用户背景图,外壳保持中性。

可访问性基线

工作目标 WCAG 2.2 AA,作为发布闸门而非加分项。

  • 正文对比度 ≥ 4.5:1,大字 ≥ 3:1,UI 组件与相邻面 ≥ 3:1;焦点环与相邻态 ≥ 3:1。
  • 所有可交互元素键盘可达:动作用 <button>,导航用 <a href>,不要用裸 <a> 占位。
  • 可见焦点环(:focus-visible),绝不 outline:none 无替代。
  • 触控目标 ≥ 24×24px(AA);图标按钮补 aria-label,装饰图标 aria-hidden。
  • 表单标签可见并关联;错误 role="alert" + aria-describedby。
  • 地标语义:header / nav / main / aside / footer;单一 h1,标题层级不跳级。
  • 位移 / 缩放动效尊重 prefers-reduced-motion;闪烁 ≤ 3 次/秒。
