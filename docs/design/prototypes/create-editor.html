第 3 步 · 属性系统

属性完全自定义,后端不硬编码。类型决定合并方式:数值累加(如理智)、标量覆盖(如位置)、集合增删(如物品)。隐藏=只供 AI 参考、玩家看不到;渐显=剧情揭示后才显示。
